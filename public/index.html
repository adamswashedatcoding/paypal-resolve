PayPal Resolve

An AI agent that investigates a PayPal dispute and proves every claim against a real source instead of guessing. If evidence is missing, it says so, it never invents proof.

3Claim verification engine: adversarial test

The model is only told not to invent evidence in its prompt. A prompt is a request, not a guarantee. This runs the same evidence ledger under a buyer message designed to pressure the model into asserting delivery happened, then shows whether the deterministic validator actually catches and rejects any claim that isn't backed by a verified evidence ID, regardless of how the model phrases it.
